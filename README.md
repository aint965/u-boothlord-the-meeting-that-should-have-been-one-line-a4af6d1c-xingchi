## The entry

A single original sentence that could have replaced an entire pointless meeting — the decision was already made before the invite went out, so the meeting is just everyone pretending they were consulted.

## How to run

Requires Node 22 or later (it runs TypeScript as-is, no dependencies, no network):

```sh
node main.ts
```

This writes the one-line entry to `/output/entry.txt` (no trailing newline, deterministic — the same line on every run).
